## Changes and decisions

Three new skills: `statechart`, `ketchup-video`, and
`maintain-formal-verification-skill`. All three are harness-neutral and ship
unchanged. The pack now contains 58 skills, 57 of them gated by
`disable-model-invocation`.

`statechart` draws TLA+ models as Mermaid statecharts and turns an agreed
chart into a TLA+ skeleton. It needs `node` and installs TLC and Java through
`mise` on first run, or reads `TLA2TOOLS` and `JAVA`. Those prerequisites are
the same on every harness, Cursor included, so they add no ledger axis.

Setup gains a one-time formal verification offer, ported to
`setup-pstack-anywhere` as step 8. `reflect` gains a rule against editing a
cached plugin copy, with the destination expressed as the harness skill root or
the manager's override. Swarm's step renumbering also fixes the same bug in the
port. The worktree audit takes upstream's GNU-stat detection and keeps the
port's transcript coverage handling.

`package.json` now runs `bun test ./test/`. The bare `test/` argument is a name
filter in Bun, so it also matched the statechart suite under
`skills/statechart/scripts/test/`, which is a `node --test` suite.

  sessions: LAST_CHAT dates resolved through the merged stat path on macOS.
- Statechart, exercised: `from-chart` on the bundled `upload.mmd` (no bugs,
  round-trip unchanged) and `sync.mmd` (one broken rule drawn as a two-step bug
  path, PNG reviewed). First run installed TLC and Java through mise.
- Statechart suite under `node --test` on macOS: 142 of 150 pass with a
  resolved `TMPDIR`. With the default `/var/folders` `TMPDIR`, 18 fail because
  the tests expect relative paths that the `/var` to `/private/var` symlink
  breaks, and one mise trust test fails. The 4 remaining failures are
  rename-fault injection tests. The scripts are byte-identical to upstream, so
  these are upstream test portability issues on macOS, not port changes.
