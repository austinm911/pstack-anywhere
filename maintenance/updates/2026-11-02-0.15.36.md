## Changes and portability review

- Statechart replaces its mjs scripts with a TypeScript compiler and a POSIX launcher for Node, Bun, or Deno. It checks TLA+ with pinned TLC and Java, writes a chart and shortest paths for broken rules, and leaves output untouched on errors or signals. The old chart-to-model workflow is removed. Source and corpus remain byte-identical to upstream. Pele is an npm renderer independent of the harness.
- Interrogate now runs isolated adversaries and accepts only failures the lead reproduces. Old templates and rubric files are removed. Delegate identity, roles, and inherited permissions resolve through the capability table.
- Arena replaces rejected seats and skips a cross-judge when no model from another family can run. Setup describes the same policy. The port discovers valid models instead of naming Cursor model identifiers.
- Autopilot-stack becomes Autopilot-full without merging, stacking only dependent work. Autopilot accepts the new blocking and concurrent-change rules. Installed-root rereads, native wakes, driver roles, and project run stores remain portable substitutions.
- Orchestrate delegates through native tools and removes the CLI. Its Project tracker/store assumption is the new project_store axis and scenario. Retire the obsolete Graphite axis. Recovery keeps exact briefs, reports, pending gates, and actual-effect reconciliation through native file tools. Older units.tsv files are read once into the tracker, without replaying uncertain writes.
- Import verification accepts a source-backed empty orchestration inventory and rejects a retained local runtime. A Git fixture covers the upstream deletion. Remove the recovery test for the deleted runtime.
- Ketchup-video adds subtitles and measured holds. Explain the Number writes the decision before measurement. Poteto-mode restates task intent and avoids rejected model retries.

- Poteto-mode's `bun run test` passes all 61 tests. Its strict watcher typecheck passes.

The command is `node --disable-warning=ExperimentalWarning --test --test-reporter=dot test/*.test.ts` from its scripts directory, with `TMPDIR=/private/tmp`, `TLA2TOOLS`, and `JAVA` set to the installed tools. This includes generated-model comparisons against plain TLC, config parsing, signal cleanup, output preservation, and Pele and Mermaid rendering.
- A first replay-only run found one launcher-symlink test failure under macOS's aliased temp directory. The full run with the canonical temp directory passes that test. Upstream runtime and test bytes remain unchanged.
- The real launcher checks CounterStop with exit 0 and CounterInstance with exit 1. The latter report retains the qualified `C!Up` and `C!Back` action names and the property loop.
- All 407 files in the new statechart tree match the selected upstream source byte for byte.
- Installation is tracked separately by Loadout's vendor pin and installed doctor. Fresh-session discovery and whole-workflow multi-harness reruns remain unverified.
