## Strategy and reproduced failures

Git ancestry owns the accepted import history. A shared mutable import branch no longer controls updates across worktrees. The baseline command preserves the current tree and cannot bless an edited pin once import history exists. Updates pin a full descendant source revision and stop before committing so adaptations receive review.

The fixture loop exposed ignored-file overwrite despite Git's merge flag, pin/history mismatch, and verification that could trust a locally forged runtime manifest. The importer now explicitly checks ignored collisions and verifies runtime hashes against upstream Git blobs. Shallow history is rejected for operations that depend on ancestry. Abort/retry and sibling-worktree fixtures exercise recovery without moving a shared import pointer.

The strict portability gate now catches literal Task-tool assumptions and a presumed MCP directory. Updated instructions discover real history formats and tool catalogs, map native worker permissions, and report unavailable capabilities. Review automation and specialized delegates cannot silently become successful generic reviews.
